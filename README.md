## 📝 What is dev-setup?

dev-setup helps you prepare your computer to develop software. It installs over 40 useful tools with one command. You do not need to install each tool by yourself. dev-setup works on Windows, macOS, Ubuntu, and Kali Linux.

It has an easy menu that lets you pick what you want. You can also run it in a dry-run mode to see what it will do before it changes anything.

---

## 💻 System Requirements

Before you start, make sure your Windows PC meets these requirements:

- Windows 10, 11, or later.
- 4 GB of RAM or more.
- At least 10 GB of free disk space.
- Internet connection to download tools.
- Administrator rights to install software.

## 🔧 How dev-setup Works

The program uses automation scripts to install software silently. It checks your system for existing tools and updates where needed.

If a tool is already installed, dev-setup skips or upgrades it. This saves time and avoids duplication.
